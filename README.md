# Research Opportunity Portal

A full-stack web app that lets faculty post, update, and manage research opportunities in one place, so students don't have to track openings across email, WhatsApp, and noticeboards.
.

## GitHub Repository
https://github.com/malikwasiq111/research_opportunity_portal

## Tech Stack
- **Backend:** Python (Flask) — REST API
- **Database:** MySQL
- **Frontend:** HTML, CSS, vanilla JavaScript, Bootstrap 5
- **API testing:** Postman
